DeathChest

SUPER2FH2026年9月5日大约 6 分钟自研插件Survival-MainSurvival-Industry

DeathChest 是 NPUcraft 自研的 Paper 死亡箱插件：玩家死亡后，插件只读取事件最终的掉落列表，按配置计算费用并保存实际掉落物。死亡箱默认先私人保护 12 小时，再公开 3 天，到期后按配置掉落或删除剩余物品。源码与完整说明见：github.com/NPUcraft/DeathChest。

适用范围

本插件安装在 生存服-主服 与 生存服-工业服。资源服为死亡不掉落，一般不会生成死亡箱。若世界开启了原版 KeepInventory，本次死亡也不会创建死亡箱。

已替代 AngelChest

本站已弃用 AngelChest（天使宝箱）。死亡物品回收现由本插件负责。个人开关请使用 /dc on、/dc off，不要再使用 /actoggle；取回物品请对死亡箱 潜行右键。

一、死亡后怎么取回物品

  • 死亡时，实际掉落物会进入附近的受保护箱子；箱子上方有动态全息，可看到主人、状态与倒计时。
  • 右键打开箱子，自行拿走需要的物品。
  • 潜行右键执行快速取回：优先把头盔、胸甲、护腿、靴子和副手装进空槽，再与背包已有物品堆叠，最后放入空格；装不下的继续留在箱内。
  • 箱子被取空后会自动消失。保护期内非主人无法打开或破坏；到期公开后其他人可以打开。
  • 找不到安全落箱位置时，物品会进入恢复仓库（不收费、不生成实体箱）；你上线后插件会尝试把物品塞回背包。

箱子 ID 形如 DC-玩家名-yyyyMMdd-HHmmss-SSS；同一次死亡若生成多只箱子，会追加 -P2、-P3。

二、玩家指令

主命令别名为 /dc。普通玩家在 /deathchest help 中只会看到下列基础命令。

命令说明
/dc help查看帮助
/dc on、/dc off开启或关闭个人死亡箱（会持久保存；默认开启）
/dc status查看功能是否开启、活动箱数量和最近位置
/dc info预览自己最近一次死亡箱快照
/dc info all列出自己的全部死亡记录
/dc info activate列出自己的活动死亡箱
/dc info inactive列出自己已提取 / 已恢复的死亡箱
/dc unlock <箱子ID>立即公开自己的指定死亡箱

带筛选的 /dc info 会给出可点击列表；点击条目打开只读物品界面。普通玩家只能查看自己的记录。

没有 /retrieve、/recover、/remove 等命令；快速取回只通过潜行右键完成。

三、费用、经验与余额不足

以下为文档编写时插件默认配置；若管理组改过 config.yml，以游戏内提示与群内公告为准。本站经济一般为西瓜币（coins），详见 经济系统。

  • 计费：基础价 + 等级价 + 背包价，再取整，并限制在上下限内。
    默认基础价 200，每级 2，每个实际掉落物品栈 20，上限 1200。
    示例：30 级、掉落占用 20 个物品栈时，价格为 200 + 30×2 + 20×20 = 660。
  • 经验：默认按 70% 保留，其余清零且不掉经验球。
  • 关闭经济或 Provider 为 NONE 时不扣费，死亡箱仍会创建。
  • 余额不足（默认 NORMAL_DROP）：不扣费、不创建死亡箱，物品按原版掉落。其他可选策略为立即公开箱（PUBLIC_CHEST）或扣光余额后仍建保护箱（TAKE_ALL）。
  • 经济插件、货币不可用，或查余额 / 扣款失败时，不会改成免费保护箱，本次物品按原版掉落。
  • /dc off 后本次不创建死亡箱，但仍会留下一条「未创建」记录。

四、保护、公开与到期

默认生命周期：

  1. 创建后私人保护 12 小时。
  2. 到期后自动公开，公开期 3 天。
  3. 公开期满后移除箱子，剩余物品默认掉在原处。

保护期内会阻止非主人打开和破坏，并按配置防止爆炸、活塞、漏斗抽物。主人可以敲碎自己的箱子；非空箱的剩余物品会先写入恢复仓库，写入失败则取消破坏。公开后他人敲碎箱子时，剩余物品仍进入箱子主人的恢复仓库，破坏者不会因此获得快速取回权限。

执行 /dc unlock <箱子ID> 会立即公开，并从执行时刻重新计算完整公开时长。公开期配置为 0 时表示公开后永不自动到期。

五、不死图腾与诅咒

  • 致命伤害发生时，若主手、副手都没有图腾，插件会把背包里的图腾换到副手，让原版图腾机制生效（创造 / 旁观模式除外）。该功能与死亡箱总开关相互独立。
  • 消失诅咒物品不会进入死亡箱，也不会写入死亡快照。
  • 绑定诅咒物品可以正常掉落并保存。

六、权限（摘要）

普通玩家默认可用：deathchest.use、status、toggle、info、unlock、retrieve。

管理员常用节点（默认 OP，或包含在 deathchest.admin 中）：

节点用途
deathchest.info.others查看其他玩家的记录与快照
deathchest.teleport/dc tp <箱子ID> 传送到活动箱
deathchest.unlock.others公开他人箱子
deathchest.restore / restore.exp / restore.force增量恢复或 Force 覆盖
deathchest.reload重载配置（不会重连数据库）
deathchest.bypass / break.bypass / retrieve.bypass绕过打开、破坏或快速取回限制

完整权限表、管理员恢复规则与存储说明见 GitHub 仓库 README。

七、常见问题

  • 提示余额不足或物品散落一地
    默认余额不足会走原版掉落。先确认西瓜币余额，或查看 经济系统。
  • 找不到死亡箱
    使用 /dc status 或 /dc info activate 查看最近位置；高空、虚空、岩浆死亡时，插件会在附近寻找安全陆地。仍没有实体箱时，物品可能已进入恢复仓库，上线后注意系统提示。
  • 别人打不开我的箱子
    仍处于私人保护期。可用 /dc unlock <箱子ID> 提前公开，或等保护倒计时结束。
  • 关闭个人死亡箱
    /dc off 后死亡不再生成箱子；需要时再 /dc on。没有个人设置时，默认开启。
  • 想预估下次死亡费用
    若服务器安装了 PlaceholderAPI，可用 %deathchest_estimated_price%（别名 %deathchest_estimated_cost%）。最终扣费仍以死亡事件里的实际掉落为准。
