小游戏挂在同一条群组入口上，从 [登录大厅](../Lobby.md) 走对应传送门，或使用 `/server <后端ID>`。这些子服**不**和生存组同步背包。

## 现开

- **[Bingo](./Bingo.md)** — 宾果收集，限时组队  
- **[船坞](./Shipyard.md)** — 和平建造向（造船 / 摆场景）  
- **[方块躲猫猫](./HideAndSeek.md)** — 猎手与方块游侠  

## 未开放 / 以门为准

- **[街机](./Arcade.md)** — 大厅仍有通往 `GameArcade` 的门，服是否在线以现场为准

## 经典谢幕游戏档案馆

那些曾闪耀舞台的精品游戏，虽已完美谢幕却永远鲜活在我们的记忆中：

- **蛋糕塔**  
  史诗级 Roguelike 冒险地图，隐藏剧情解谜；可邀请伙伴共闯魔塔。

- **柱联璧合**  
  原版攻防占地，羊毛战略资源争夺。

- **梦回盘灵**  
  东方玄幻 RPG 重制，多线剧情。

- **起床战争**  
  经典 MC 竞技校园特供版。

- **你建我猜**  
  极速建造 + 猜谜。
