**HuskSync** 负责把玩家的背包、末影箱、经验、进度等数据在多个 Paper 子服之间对齐。本站三个生存子服共用**同一套玩家数据**，在主服、工业服、资源服之间切服时，身上的物品会跟着走。

::: info 完整文档
官方文档：[HuskSync Docs](https://william278.net/docs/husksync)；项目页：[william278.net/project/husksync](https://william278.net/project/husksync)；源码：[WiIIiam278/HuskSync](https://github.com/WiIIiam278/HuskSync)
:::

::: info 适用范围

本插件安装在 **生存服-主服**、**生存服-工业服**、**生存服-资源服**，三服写入**同一个数据库**，因此背包与多数玩家数据跨这三服同步。

**登录大厅不在同步范围内**。大厅里的物品、经验不会带到生存子服，也不要从生存子服「带进」大厅。

西瓜币余额由 [经济系统](/SurvivalGuide/EconomicSystem/)（CoinsEngine）单独记账，**不是** HuskSync 同步的。

:::

## **一、切服时会发生什么**

1. 离开当前生存子服时，插件把你的当前数据写入共享库。
2. 进入另一个生存子服时，从同一库读出数据并应用到角色上。
3. 同步完成前，角色处于锁定状态：**全部指令都会被拦截**。界面语言为中文，进度提示出现在**动作栏**（快捷栏上方）。
4. 看到同步完成后再移动、开箱或输入指令。连续来回切服、或在提示未结束时乱点，容易造成短暂「空背包」错觉。

本站使用逐步对齐的同步模式，并配合实时消息通道，正常情况下切服后很快就能继续玩。若动作栏长时间停在同步中，可小等片刻或重进该子服；仍异常请向管理组说明刚才经过的子服与时间。

## **二、会同步 / 不会同步**

下列为**当前服内策略**的摘要，便于建立预期；管理组日后若调整同步项，以游戏内实际表现为准。

**会在三服之间对齐：**

- 背包与快捷栏（含当前手持槽位）
- 末影箱
- 生命、饥饿、经验与等级
- 游戏模式、飞行状态
- 药水效果、部分属性（如最大生命）
- 进度（Advancements）与部分统计
- 部分插件写入玩家的持久化数据
- 在制图台**锁定**后的地图（未锁定的普通地图无法可靠跨服）

**刻意不同步：**

| 项目 | 说明 |
| --- | --- |
| 坐标与所在世界 | 各子服保留自己的上次下线位置。`/zf`、`/gyf`、`/zyf` 切服后，会出现在**目标子服**上次离开的地方，而不是主服脚下那一格。 |
| 登录大厅物品 | 大厅未加入同步集群。 |
| 西瓜币 | 见 [经济系统](/SurvivalGuide/EconomicSystem/)。 |

::: tip 和「三个世界一套经济」的关系

生存组三世界共用西瓜币，同时共用这套背包数据。你可以在主服囤货、去资源服挖矿、再回工业服挂机，物品栏是连续的；钱在 Tab 列表里看，物品在背包里看。

:::

## **三、死亡、死亡箱与切服**

- 死亡时会额外留一份数据快照（即使当时该保留的物品为空也会记一笔）。
- **生存服-主服 / 工业服** 的地上掉落由 [DeathChest](/PluginIntroduction/DeathChest) 接管：先去死亡箱取回，再考虑切服。
- 资源服一般为死亡不掉落，同步的是「仍留在身上」的那套物品。
- 死亡后立刻切到另一子服时，插件仍会尽量带着死亡相关数据走；但未取回的死亡箱物品**不会**因此出现在另一个世界的背包里。

## **四、玩家需要用指令吗**

日常游玩**不用**执行 HuskSync 指令。查快照、改背包、回滚等见下一节，默认仅管理组可用。

若你确认同步完成后背包仍不对：

1. 不要反复切服「试出来」。
2. 记下最近一次正常时的子服、大致时间，以及是否刚死亡、刚用过死亡箱。
3. 向管理组反馈，由他们从快照恢复。本站会保留较长时间的自动备份（切服、存盘、死亡等都会生成记录）。

## **五、管理员命令**

在**主服 / 工业服 / 资源服**任一端执行即可（三服共用同一库）。大厅没有本插件。完整权限表见 [官方 Commands](https://william278.net/docs/husksync/commands)，可用 `husksync.command.<命令>.*` 一次授予该命令全部子权限。下列默认给 OP。

处理「背包丢了」的常用顺序：`/userdata list` → 按时间和保存原因点开确认（或 `/inventory` 只看背包）→ `/userdata restore`。聊天列表里的 Manage 按钮与手打子命令等价。

### **1. 快照 `/userdata`**

别名 `/playerdata`。`<版本>` 为快照 UUID，可在列表里点击复制。

| 命令 | 说明 |
| --- | --- |
| `/userdata list <玩家> [页码]` | 列出该玩家快照，新的在前；带星号的已被钉选，不会被自动轮换删掉 |
| `/userdata view <玩家>` | 查看**最新**一份快照总览 |
| `/userdata view <玩家> <版本>` | 查看指定快照 |
| `/userdata restore <玩家> <版本>` | 回滚到该快照。在线则立刻套用；离线则下次登录生效。生命值至少会恢复到 1，避免回滚成死亡状态 |
| `/userdata save <玩家>` | 把该玩家**当前在线数据**再存一份（玩家须在**当前这台子服**上线） |
| `/userdata pin <玩家> <版本>` | 钉选 / 取消钉选。再执行一次即切换 |
| `/userdata delete <玩家> <版本>` | 删除该快照，并清掉缓存中的对应数据 |
| `/userdata dump <玩家>` | 把最新快照上传到网页，用于排查 |
| `/userdata dump <玩家> <版本> <web\|file>` | `web` 上传；`file` 写到本机 `plugins/HuskSync/dumps/` |

保存原因（列表里的旗标）常见有：切服/下线 `disconnect`、世界存盘、关服、死亡、用 `/inventory` / `/enderchest` 改过、以及回滚产生的 `backup restore`。本站对「用命令改背包 / 改末影箱 / 回滚」生成的快照会**自动钉选**，避免被轮换清掉。

::: warning 回滚会覆盖整份同步数据

`restore` 不只还背包，还会覆盖末影箱、经验、进度、生命饥饿等**当时快照里有的同步项**。只想改物品时，用下面的 `/inventory` 或 `/enderchest`，不要整份回滚。

三服共用数据库：在工业服恢复成功后，玩家再进主服也会是恢复后的那套数据。

:::

### **2. 查看 / 编辑物品**

须在游戏内执行（控制台不可用）。打开**当前最新**数据且你有 `.edit` 权限时，关闭界面即写入共享库并推到其他子服；打开**历史快照**时只读，改了也不会保存。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/inventory <玩家>` | `/invsee`、`/openinv` | 打开当前背包；有 `husksync.command.inventory.edit` 时可直接改 |
| `/inventory <玩家> <版本>` | 同上 | 只读查看该快照里的背包 |
| `/enderchest <玩家>` | `/echest`、`/openechest` | 打开当前末影箱；编辑需 `husksync.command.enderchest.edit` |
| `/enderchest <玩家> <版本>` | 同上 | 只读查看该快照里的末影箱 |

### **3. 插件本身 `/husksync`**

| 命令 | 说明 |
| --- | --- |
| `/husksync`、`/husksync about` | 插件信息（一般玩家也能看） |
| `/husksync status` | 数据库、消息通道、同步状态 |
| `/husksync reload` | 重载配置与语言文件，**不会**重连数据库 |
| `/husksync update` | 检查上游是否有新版本 |
| `/husksync dump` → `/husksync dump confirm` | 上传系统诊断包（先确认再执行） |
| `/husksync migrate` | **仅控制台**。从旧版或其他插件迁数据，日常不要动 |
| `/husksync forceupgrade` | **仅控制台**。强制升级遗留数据格式 |

`/userdata dump` 在部分版本里即使是 OP 也可能要单独给 `husksync.command.userdata.dump`。迁库、改数据库地址请走停服与配置，不要指望 `reload`。

## **六、常见问题**

- **刚进服指令没反应 / 打不开背包**  
  仍在锁定同步。看动作栏是否还在提示；完成后即可。不要用客户端模组强行操作。

- **切到另一个生存子服后出现在很远的地方**  
  坐标不同步。那是该子服上次的下线点，不是传送失败。

- **大厅里的装备不见了**  
  大厅不同步。生存三服之间的物品不会出现在大厅，反之亦然。

- **地图变成空白**  
  未锁定的地图不能跨服保存画面。需要长期携带的地图，请先在制图台锁定。

- **钱还在但背包空了，或反过来**  
  货币与物品走两套系统。先等同步结束，再分别核对 Tab 余额和背包；只丢物品时按第四节联系管理组查快照。
